# مِشراك — ذكاء الشراكات

مشروع **Project 1 — AI Product Development and Monitoring**. يساعد فرق الاستراتيجية على مقارنة فرص الشراكات والاستثمار بين شركات مدرجة في السوق الرئيسية السعودية، ثم متابعة مؤشرات العلاقة بعد اعتمادها.

يحتوي كتالوج النسخة على **27 شركة مدرجة** موزعة على الاتصالات والطاقة والبتروكيماويات والمصارف. مرجع أسماء الشركات ورموزها هو [دليل المُصدرين في تداول السعودية](https://www.saudiexchange.sa/wps/portal/saudiexchange/trading/participants-directory/issuer-directory?locale=en). رموز الإدراج لا تعني توفر بيانات مالية داخل التطبيق. لم تُدرج أرقام مالية غير متحققة؛ استيراد القوائم المالية يحتاج ملفاً موثقاً ورابط مصدر رسمي.

هناك علاقة شراكة واحدة وبيانات KPI شهرية **مُحاكاة لأغراض العرض** بين شركتين حقيقتين. هذا لا يعني أن الشركتين أبرمتا الشراكة فعلاً. لا يقدم المنتج نصيحة استثمارية ولا يتنبأ بعوائد.

## المتطلبات

- Python 3.11+
- اختياري: مفتاح API متوافق مع واجهة OpenAI لتوليد الشروحات. من دون مفتاح يعمل التطبيق بوضع تجريبي حتمي ومُعلّم بوضوح.

## تشغيل على Windows PowerShell

```powershell
cd C:\Users\ALOSTATH\Projects\CompatibilityMatch-AI
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env

```

افتح http://127.0.0.1:5000 . ينشئ التطبيق قاعدة SQLite ويحمّل الشركات عند التشغيل الأول. عند الترقية من النسخة السابقة، يزيل السجلات الخيالية القديمة ويحمّل قائمة الشركات المدرجة الجديدة. لا يحذف السجلات التي لا تحمل رموز DEMO.*.

## متغيرات البيئة

لربط Gemini، أنشئ مفتاحاً من [Google AI Studio](https://aistudio.google.com/apikey)، ثم انسخ `.env.example` إلى `.env` وضع المفتاح في `GEMINI_API_KEY`. يستخدم التطبيق افتراضياً `gemini-3.5-flash-lite` عبر واجهة Gemini المتوافقة مع OpenAI. أعد تشغيل التطبيق بعد حفظ المفتاح. ملف `.env` مستثنى من Git؛ لا ترفع المفتاح إلى GitHub. عند ترك المفتاح فارغاً يعمل التطبيق بوضع تجريبي بقواعد ثابتة، ولا يرسل طلبات إلى Gemini.

## خطوات العرض

1. **اكتشاف شريك:** الاكتشاف الذكي ← stc (7010) ← شراكة استراتيجية. جرّب أيضاً مقارنة stc مع موبايلي أو زين، أو أرامكو مع سابك.
2. **تحليل:** افتح المقارنة. راجع درجة النشاط/القطاع، درجة الثقة، وملاحظة غياب البيانات المالية الموثقة.
3. **متابعة علاقة افتراضية:** مراقبة الشراكات ← «شراكة تكامل القنوات — مثال مُحاكى». الإيراد الفعلي 650,000 مقابل هدف 1,000,000 (65%). العلاقة والمؤشرات افتراضية ولا تمثل عقداً حقيقياً.
4. **مراقبة النظام:** شغّل تحليلاً، ثم استخدم زر محاكاة timeout لترى الحدث المسجل ومقاييس قاعدة البيانات.

## استيراد بيانات مالية موثقة

استخدم الأعمدة في `data/companies_demo.csv` كقالب، وأدخل فقط حقائق لها مصادر رسمية. الشركات الموجودة جاهزة في الكتالوج؛ أضف السنة المالية ورابط التقرير الرسمي ثم شغّل `python scripts/import_companies.py path.csv`. يحدّث السكربت البيانات للشركة المعروفة بالرمز ويمنع استيراد بيانات مالية معلّمة كتجريبية.
